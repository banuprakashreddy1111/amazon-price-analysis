# Amazon Price Analysis

## Project Overview

This project analyzes Amazon product pricing data using Python and data analysis techniques.

The project focuses on exploring product prices, identifying pricing patterns, and understanding the characteristics of products available on Amazon.

The analysis is performed using a Jupyter Notebook.

## Objectives

- Analyze Amazon product pricing data
- Understand product price distributions
- Explore relationships between product attributes and prices
- Identify pricing patterns and trends
- Perform data cleaning and preprocessing
- Generate useful insights through data analysis and visualization

## Analysis Performed

The project includes analysis such as:

- Data loading and exploration
- Data cleaning
- Handling missing values
- Data preprocessing
- Descriptive statistics
- Price analysis
- Product-level analysis
- Distribution analysis
- Data visualization
- Correlation analysis
- Business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
